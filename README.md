# GRC206 – Design a Security Awareness Program

## Project Overview

This project presents a proposed Security Awareness Programme for **Northbridge Logistics**, an organisation with approximately 800 employees working across its head office, warehouses, and remote sales teams.

The programme is designed to address human-related cybersecurity risks, including invoice fraud, phishing, password reuse, and accidental exposure of regulated customer information.

The aim is to improve employees' security awareness, encourage safer workplace practices, and reduce security incidents through continuous education and monitoring.

## Programme Approach

The programme follows five key stages of the security awareness lifecycle:

1. **Assess:** Identify major human-related security risks, understand employee awareness levels, and establish a baseline.
2. **Plan:** Set measurable security awareness objectives, assign responsibilities, and develop role-based training.
3. **Deliver:** Provide practical training through workshops, digital learning, team briefings, awareness materials, and phishing simulations.
4. **Measure:** Monitor training completion, phishing simulation results, reporting behaviour, password and MFA compliance, and security incidents.
5. **Improve:** Review programme performance quarterly, collect employee feedback, recognise positive security behaviour, and update training where necessary.

## Key Programme Components

- Human-driven cybersecurity risk assessment.
- Employee segmentation and role-based awareness training.
- Measurable security awareness objectives.
- Phishing and invoice fraud simulations.
- Password security and multi-factor authentication awareness.
- Protection of customer and organisational information.
- Incident reporting and a supportive, no-blame reporting culture.
- Security awareness performance metrics.
- Quarterly programme evaluation and continuous improvement.
- A 12-month implementation calendar.

## Project Deliverables

This repository contains the written GRC206 assignment, including:

- Security risk assessment and audience analysis.
- Programme objectives and assigned responsibilities.
- Training and awareness delivery strategies.
- Monitoring and evaluation metrics.
- Continuous improvement recommendations.
- A 12-month security awareness programme calendar.
- A reflection on the programme design process.

## Expected Outcomes

The proposed programme aims to:

- Reduce employee susceptibility to phishing and invoice fraud.
- Improve password and MFA compliance.
- Encourage early reporting of suspicious activities.
- Reduce employee-related data handling violations.
- Build a sustainable security-conscious workplace culture.

## Important Note

This is an academic programme design based on the fictional Northbridge Logistics scenario. The objectives, targets, implementation activities, and expected outcomes are proposals and should not be interpreted as evidence of an already implemented programme or measured organisational results.
